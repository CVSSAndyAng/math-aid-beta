# Realistic movable compass and protractor

The Student Geometry Construction Board now uses movable construction instruments rather
than simple click-drag shortcuts.

## Compass
- visible two-leg compass instrument;
- draggable hinge to reposition the whole compass;
- draggable needle handle to alter the opening/radius;
- draggable pencil handle;
- pencil movement sweeps/draws an arc around the needle point;
- current compass opening is displayed;
- suitable for construction arcs, loci and transferring lengths.

## Protractor
- visible translucent semicircular protractor;
- 0–180° graduation marks;
- draggable centre to position the protractor on a vertex;
- rotation handle to align its baseline with an existing ray;
- drag from the centre to create/read a second ray;
- measured angle is displayed live.

## Existing tools retained
- Apple Pencil / freehand pencil
- straightedge
- ruler
- eraser
- undo
- clear
- grid
- Save to notes

The component version is bumped to v4 so Streamlit loads the new frontend rather than a
cached earlier version.
