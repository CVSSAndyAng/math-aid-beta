# Student geometry construction working tool

Added to Lesson whiteboard:
- Apple Pencil/freehand pencil
- straightedge
- compass/circle
- protractor/angle
- ruler/measurement
- eraser
- undo
- clear
- Save to notes

Saved construction working is stored as a PNG in the student's persistent lesson notes,
so it can be included with the existing notes export workflow.

This is an original built-in Math Buddy tool inspired by the requested construction-tool
workflow; it does not embed or copy the MathsPad interface.
